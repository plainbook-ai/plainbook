# Contributing to Plainbook

Plainbook is an open-source project, released under the BSD 3-Clause license.
Contributions are welcome.

For development setup, architecture notes, and how to run the tests, see
[DEVELOP.md](DEVELOP.md).

## Licensing of contributions

**All contributions to Plainbook are licensed under the BSD 3-Clause license**,
the same license the project itself is released under. By submitting a pull
request, patch, or any other contribution to this repository, you agree that
your contribution is licensed under those terms.

You retain copyright in what you write. You are granting the project — and
everyone who receives it — the right to use, modify, and redistribute your
contribution under BSD 3-Clause. This is what keeps Plainbook permanently
open source: there is no path by which a contribution can later be withdrawn
or relicensed to restrict downstream use.

Contribute only code you have the right to license this way. In particular, do
not contribute code copied from a project under an incompatible license, code
you wrote under an employment or consulting agreement that assigns it to
someone else, or code carrying third-party terms you have not checked. If a
contribution incorporates third-party material, say so in the pull request and
name the license.
